# Clean Circle 🌱

Clean Circle is an AI-powered community cleanliness platform designed to encourage responsible waste disposal, community participation, and sustainable daily habits.

## 🚀 Overview

Clean Circle aims to make waste management more engaging and community-driven. Users can report waste, track cleanliness activities, build positive habits, and understand their environmental impact.

The platform combines a simple, user-friendly interface with AI-assisted development to create an interactive digital solution for cleaner communities.

## 🎯 Problem

Improper waste disposal and low community participation contribute to:

* Unclean public spaces
* Poor waste-management practices
* Lack of awareness about proper disposal
* Limited community engagement
* Difficulty tracking individual environmental impact

## 💡 Solution

Clean Circle provides a centralized platform where users can:

* Report waste problems
* View and manage cleanliness reports
* Learn about proper waste disposal
* Track daily cleanliness habits
* Monitor personal and community impact
* Participate in community cleanliness activities

## ✨ Key Features

### 🗑️ Report Waste

Users can report waste-related issues and provide information about locations and waste conditions.

### ♻️ Proper Disposal

Provides guidance and awareness about responsible waste disposal.

### 📊 Community View

Allows users to understand community cleanliness activity and participation.

### 🌱 Daily Habit Checklist

Encourages users to develop consistent environmentally responsible habits.

### 🔥 Streak Tracking

Users can maintain cleanliness streaks and stay motivated to continue positive habits.

### 📈 Impact Tracking

Displays the user's contribution and environmental impact.

### 👥 Community Cleanliness

Encourages collective participation rather than focusing only on individual actions.

## ⚙️ Getting Started

### Prerequisites

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/sathvika-nainappagari/Clean_Circle.git
```

Navigate to the project directory:

```bash
cd Clean_Circle
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.
